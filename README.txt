HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to start at the login page.
4. Use the navigation links to explore all pages.
5. If browser restrictions affect images, connect to the internet; artwork images are loaded from Wikimedia Commons.

FEATURES
- Responsive layout for desktop and mobile
- Login and sign-up form validation
- Demo account information stored in browser localStorage
- Gallery cards with artwork image, artist name, year and detail link
- Individual artwork information and related works
- Consistent typography, colours and navigation

IMPORTANT
This is a front-end student assignment prototype. Login/signup are simulated in the browser only; there is no real server, database, password security or production authentication. Artwork images are loaded from Wikimedia Commons and therefore need an internet connection.
